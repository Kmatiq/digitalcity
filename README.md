# Stadsplattan

Interaktiv 3D-diorama av Helsingfors centrum (2 × 2 km, 50 m djup) i webbläsaren —
three.js + 3DTilesRendererJS + React, med öppna data från Helsingfors stad (CC BY 4.0).

```bash
npm install
npm run dev
```
